Studio Breve als App

Sie können diese Website wie eine kleine App auf dem Handy nutzen – ohne Shop und ohne Tracking-Cookies. Die Installation läuft über den Browser, nicht über einen App-Store.

Android

Wenn Ihr Browser die Installation anbietet, erscheint unten die Schaltfläche. Sonst öffnen Sie das Menü des Browsers und wählen „App installieren“ oder „Zum Startbildschirm hinzufügen“.

Ihr Browser bietet die automatische Installation gerade nicht an. Bitte nutzen Sie die Schritte oben.

Studio Breve ist auf diesem Gerät bereits als App verfügbar.

iPhone und iPad

Öffnen Sie diese Seite in Safari, tippen Sie auf die Teilen-Taste und wählen Sie „Zum Home-Bildschirm“. Danach erscheint Studio Breve wie eine App auf dem Bildschirm.
